## Overview
This repository contains the source code for the FAQ page. The goal of this project is to provide customers with instant, clear answers regarding shipping, returns, product details, and payment methods, thereby reducing customer support queries and boosting store credibility.
##✨ Features
Responsive Design: Optimized seamlessly for mobile phones, tablets, and desktop screens.
Accordion UI: Clean toggle/dropdown functionality for easy navigation through multiple questions.
SEO Friendly: Structured with proper semantic HTML tags to ensure search engine visibility.
Modern Styling: Minimalist and professional layout matching contemporary e-commerce branding.
##🛠️ Tech Stack
HTML5: Semantic markup structure.
CSS3: Flexbox/Grid for layout and smooth transitions.
JavaScript (Vanilla): Interactive accordion toggle behavior.
